# 2ss7

Разрабатываю retrieval-системы и Python backend. Основной проект, [RIVER](https://lexriver.ru), работает с вопросами по российскому праву и налогам, а также с подготовкой документов.

В RIVER я работал над всем путём от исходного документа до ответа: структурный разбор и chunking, плотные и полнотекстовые индексы, разбиение сложного вопроса на атомарные поисковые запросы, маршрутизация, слияние результатов по рангам, выбор источников, вызовы LLM и проверки готового ответа и файлов.

На 31 октября 2026 года в рабочем индексе было 602 824 успешно разобранных документа и 2 438 760 чанков. Это объём корпуса, а не оценка качества или скорости поиска.

Рабочий стек: Python, FastAPI, SQLite/FTS5, LanceDB, BGE-M3, PyArrow, JavaScript, Playwright, Linux, systemd, nginx. Исходный код сервиса и корпус закрыты. [Технический разбор RIVER](https://github.com/2ss7/river-architecture) описывает архитектуру и принятые инженерные решения.
