## MarginHash

[MarginHash](https://github.com/2ss7/marginhash-architecture) собирает предложения asic майнеров на российском рынке. Каталог показывает цены, характеристики, историю предложений, сценарную доходность и аналитику продавцов. 1 431 515 исходных наблюдений цен.

## Автоматизация заявок для handyman-бизнеса

Для handyman-бизнеса в Нью-Йорке собрал систему обработки заявок на n8n. Исполнители получают заявки с сайта в Telegram, а их ответы и статусы записываются в Google Sheets. В рабочем workflow 64 узла, включая маршруты принятия, пропуска и отмены заявки.
[Подробнее о проекте](https://github.com/2ss7/handyman-dispatch-n8n)
