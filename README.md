# 2ss7

Разрабатываю retrieval-системы и Python backend. Основной проект, [RIVER](https://lexriver.ru), ИИ-ассистент для бизнеса по российскому праву и налогам, а также с подготовкой документов.

В RIVER я работал над всем путём от исходного документа до ответа: структурный разбор и чанкование, плотные и полнотекстовые индексы, разбиение сложного вопроса на атомарные поисковые запросы, маршрутизация, слияние результатов по рангам, выбор источников, вызовы LLM и проверки готового ответа и файлов. А также в общем вся архитектура RAG системы.

На 31 октября 2026 года в рабочем индексе было 602 824 успешно разобранных документа и 2 438 760 чанков. Это объём корпуса, а не оценка качества или скорости поиска.

Рабочий стек: Python, FastAPI, SQLite/FTS5, LanceDB, BGE-M3, PyArrow, JavaScript, Playwright, Linux, systemd, nginx. Исходный код сервиса и корпус закрыты. [Технический разбор RIVER](https://github.com/2ss7/river-architecture) описывает архитектуру и принятые инженерные решения.

## MarginHash

[MarginHash](https://github.com/2ss7/marginhash-architecture) — агрегатор предложений ASIC для российского рынка. Я разработал адаптеры сбора данных из разных источников, нормализацию характеристик, сопоставление моделей и предложений, расчёт сценарной доходности и read model для Flask-каталога.

[Технический разбор MarginHash](https://github.com/2ss7/marginhash-architecture) описывает архитектуру и ограничения реализации. Исходный код и рабочие данные не опубликованы.
