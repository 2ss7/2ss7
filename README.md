# River

[RIVER](https://lexriver.ru), ИИ-ассистент для бизнеса по российскому праву и налогам, а также с подготовкой документов. 
Рабочий стек: Python, FastAPI, SQLite/FTS5, LanceDB, BGE-M3, PyArrow, JavaScript, Playwright, nginx. 
[Подробнее о RIVER](https://github.com/2ss7/river-architecture) 

## MarginHash

[MarginHash](https://marginhash.ru) собирает предложения asic майнеров на российском рынке. Каталог показывает цены, характеристики, историю предложений, сценарную доходность и аналитику продавцов. 1 431 515 исходных наблюдений цен.
[Подробнее о MarginHash](https://github.com/2ss7/marginhash-architecture)

## Автоматизация бизнеса из NYC

Для [handyman бизнеса](https://rhmny.com) в Нью Йорке создал систему на n8n. Заявки с сайта распределяются между исполнителями в Telegram, ответы и статусы сохраняются в Google Sheets, а медиа на другом хостинге.
[Подробнее о проекте](https://github.com/2ss7/handyman-dispatch-n8n)
